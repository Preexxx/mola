# Mola — Landing page

Сайт зверстаний з Figma-файлу «Mola — Landing page».

## Як відкрити

Розпакуй архів і двічі клацни на `index.html` — сторінка відкриється в браузері. Нічого встановлювати не треба.

Шрифт Inter підвантажується з Google Fonts, тому для точного вигляду потрібен інтернет. Без нього сторінка покаже системний шрифт.

## Що всередині

- `index.html` — розмітка (EN)
- `uk/index.html` — україномовна версія (перемикач мови в шапці)
- `css/style.css` — стилі
- `js/main.js` — анімації
- `js/nav.js` — мобільне бургер-меню
- `assets/` — логотип/іконка
- `robots.txt`, `sitemap.xml` — для пошукових систем (домен `mola-agency.com`, якщо реальний інший — поправити обидва файли та `canonical`/`og:url` в обох `index.html`)

## Анімації

- Поява елементів: прозорість 0 → 1 і зсув вгору на 10–24 px за 0,65 с, easing `cubic-bezier(0.22, 1, 0.36, 1)`, затримки взяті з Motion timeline у Figma.
- Hero грає одразу при завантаженні, секції 01/02/03 — коли до них доскролиш.
- Скан-лінія й пульсація кола в hero — безкінечний цикл 5 с.
- Якщо в системі ввімкнено «зменшити рух», анімації вимикаються.

## Контакт

- Контактне посилання в секції Contact веде на `mailto:mola@mola-agency.com`.
- Кнопки «Send your CV» і «Discuss a project» відкривають окремі форми: `/send-cv/`, `/discuss-project/` (і їхні UA-версії `/uk/send-cv/`, `/uk/discuss-project/`).

## Форми (Send CV / Discuss a project)

- Поля: ім'я, прізвище, телефон, телеграм; на сторінці CV додатково — файл (PDF/Word, до 10 МБ).
- Відправка йде через [FormSubmit](https://formsubmit.co/) напряму на `mola@mola-agency.com`, без бекенду.
- **Важливо:** перше повідомлення з нового домену FormSubmit надсилає на `mola@mola-agency.com` лист з підтвердженням («Activate Form») — тре клацнути один раз, інакше наступні заявки не доходитимуть.
- Після відправки форма показує повідомлення "Дякуємо" на тій самій сторінці (через `?sent=1` і `js/form.js`), без переходу на сторонній сайт.
