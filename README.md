# Mola — Landing page

Сайт зверстаний з Figma-файлу «Mola — Landing page».

## Як відкрити

Розпакуй архів і двічі клацни на `index.html` — сторінка відкриється в браузері. Нічого встановлювати не треба.

Шрифт Inter підвантажується з Google Fonts, тому для точного вигляду потрібен інтернет. Без нього сторінка покаже системний шрифт.

## Що всередині

- `index.html` — розмітка
- `css/style.css` — стилі
- `js/main.js` — анімації
- `assets/` — логотип/іконка

## Анімації

- Поява елементів: прозорість 0 → 1 і зсув вгору на 10–24 px за 0,65 с, easing `cubic-bezier(0.22, 1, 0.36, 1)`, затримки взяті з Motion timeline у Figma.
- Hero грає одразу при завантаженні, секції 01/02/03 — коли до них доскролиш.
- Скан-лінія й пульсація кола в hero — безкінечний цикл 5 с.
- Якщо в системі ввімкнено «зменшити рух», анімації вимикаються.
